<GuideSection id="module-1" index="M1" title="User identification">

Make every person individually accountable and remove shared, former-user, and generic identities.

<GuideLab id="M1-L1" title="Shared reception account" objective="Replace one shared identity with individually attributable accounts.">

1. In ADUC, open **Students >** `{{podName}}` **> Users > Staff**.
2. Disable `{{podPrefix}}-frontdesk`.
3. Create Karen O'Malley as `{{podPrefix}}-k.omalley` and the temporary worker as `{{podPrefix}}-temp.agency01`.
4. Give each account a policy-compliant password and clear **User must change password at next logon** for this lab.
5. Save an evidence summary as `{{artifactsPath}}M1-L1.txt` naming the disabled shared account and both individual replacements.

```powershell
$p = "{{podPrefix}}"
Disable-ADAccount -Identity "$p-frontdesk"
Get-ADUser -Identity "$p-frontdesk" | Select-Object SamAccountName, Enabled
```

**Success check:** the shared account is disabled, both individual accounts exist, and `M1-L1.txt` is present.

</GuideLab>

<GuideLab id="M1-L2" title="Zombie account" objective="Remove access for a terminated user and place the identity in the terminated OU.">

1. Find `{{podPrefix}}-tom.davis` under **Resources > Departments > Sales**.
2. Disable the account.
3. Remove every business-group membership; `Domain Users` remains.
4. Move the account to **Users > Terminated**.

```powershell
$p = "{{podPrefix}}"
Disable-ADAccount -Identity "$p-tom.davis"
Get-ADUser "$p-tom.davis" -Properties MemberOf |
  Select-Object -ExpandProperty MemberOf |
  ForEach-Object { Remove-ADGroupMember -Identity $_ -Members "$p-tom.davis" -Confirm:$false }
```

**Success check:** `{{podPrefix}}-tom.davis` is disabled, stripped of business access, and located in the Terminated OU.

</GuideLab>

<GuideLab id="M1-L3" title="Generic accounts" objective="Disable identities that cannot be traced to an individual and document the authorized inventory.">

**Success check:** all three generic accounts are disabled and the authorized-user CSV is nonempty.

1. Create `{{podPrefix}}-svc_backup` in ADUC.
2. Set a policy-compliant password, select **Password never expires** for this exercise, and clear **User must change password at next logon**.
3. Set its description to `Service account for nightly backup automation`.

5. In **Properties > General**, change the running identity from `{{netbiosDomain}}\{{podPrefix}}-s.jenkins` to `{{netbiosDomain}}\{{podPrefix}}-svc_backup`; provide the service password when prompted.

<GuideSection id="module-3" index="M3" title="User authentication management">

Review password evidence, harden local authentication, and ensure temporary credentials do not become permanent.

<GuideLab id="M3-L1" title="Password policy report" objective="Export the current policy and document that it was reviewed.">

1. Export the domain password policy to the exact IA artifact path.

```powershell
Get-ADDefaultDomainPasswordPolicy |
  ConvertTo-Html -Title "Password Policy Report" |
  Out-File "{{iaArtifactsPath}}PasswordPolicy_Report.html"
Start-Process "{{iaArtifactsPath}}PasswordPolicy_Report.html"
```

2. Record minimum length, complexity, lockout threshold, history, and maximum age in `{{artifactsPath}}M3-L1.txt` along with the reviewer and date.

**Success check:** the HTML report is nonempty and the review evidence file exists.

</GuideLab>

<GuideLab id="M3-L2" title="Weak local password policy" objective="Harden authentication for local accounts on your assigned server.">

On `{{sessionHost}}`, open `secpol.msc` as administrator and configure:

| Setting                   | Required value        |
| ------------------------- | --------------------- |
| Minimum password length   | 12 or more            |
| Password complexity       | Enabled               |
| Account lockout threshold | 1-10 invalid attempts |

You may set length and lockout from an elevated PowerShell session:

```powershell
net accounts /minpwlen:12 /lockoutthreshold:10 /uniquepw:24
```

Confirm with `net accounts` and a security-policy export. The domain policy is shared; only harden your own pod server's local account policy.

</GuideLab>

<GuideLab id="M3-L3" title="Change password at next logon" objective="Ensure a user replaces a help-desk-issued temporary password.">

1. In ADUC, reset the password for `{{podPrefix}}-d.chen`.
2. Select **User must change password at next logon**.
3. Save an incident summary as `{{artifactsPath}}M3-L3.txt` including the user, issue, action, and result.

```powershell
$p = "{{podPrefix}}"
Set-ADUser -Identity "$p-d.chen" -ChangePasswordAtLogon $true
Get-ADUser "$p-d.chen" -Properties pwdLastSet |
  Select-Object SamAccountName, pwdLastSet
```

**Success check:** `pwdLastSet` is `0` and the incident evidence file exists.

</GuideLab>
